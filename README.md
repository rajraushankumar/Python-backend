# Flask User Registration Backend Project

## 📌 Project Overview

This is a simple backend web application built using **Flask
(Python)**.\
The project allows users to register using a form, and the data is
stored in a JSON file.\
It demonstrates basic backend development concepts including routing,
form handling, and file-based data storage.

------------------------------------------------------------------------

## 🚀 Features

-   User Registration Form (First Name, Last Name, Email, Password)
-   Backend built with Flask
-   Data stored in a JSON file instead of a database
-   Success page after registration
-   Clean project structure

------------------------------------------------------------------------

## 🛠️ Technologies Used

-   Python 3
-   Flask
-   HTML
-   JSON (for data storage)

## ▶️ How to Run the Project

### 1️⃣ Install Flask

``` bash
pip install flask
```

### 2️⃣ Run the Application

``` bash
python app.py
```

### 3️⃣ Open in Browser

Go to:

    http://127.0.0.1:5000/
